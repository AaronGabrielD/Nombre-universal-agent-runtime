# TallerOS — Paquete de transferencia de supervisión

Este repositorio es **temporal** y existe únicamente para transferir el contexto y las instrucciones del proyecto TallerOS a un nuevo arquitecto/supervisor de ChatGPT.

## Regla principal

Este repositorio **NO es la fuente de verdad del código de TallerOS** y no debe convertirse en un repositorio de desarrollo permanente.

La fuente de verdad del código es el repositorio principal de TallerOS conectado a Lovable/GitHub.

El nuevo supervisor debe usar este repositorio para comprender:

- objetivo del producto;
- arquitectura acordada;
- estado actual;
- decisiones que ya no deben cambiarse sin justificación;
- reglas para trabajar con Lovable;
- siguiente fase autorizada.

Una vez completada la transferencia, este repositorio puede dejar de utilizarse.

## Archivos de transferencia

- `SUPERVISOR_HANDOFF.md` — documento principal para asumir el puesto.
- `PROJECT_STATE.md` — estado exacto conocido al momento de la transferencia.
- `ARCHITECTURE_CONSTITUTION.md` — principios y límites arquitectónicos.
- `LOVABLE_MASTER_INSTRUCTIONS.md` — instrucciones maestras para Lovable.
- `NEXT_ACTION.md` — próximo trabajo autorizado, sin saltar fases.
- `DECISIONS_LOG.md` — decisiones importantes ya tomadas.

## Importante

El nuevo supervisor debe leer primero `SUPERVISOR_HANDOFF.md` y después los demás documentos antes de modificar arquitectura o solicitar trabajo a Lovable.
